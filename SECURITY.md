# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in STEG Cut Tracker, please report it privately.

**Do not** open a public GitHub issue. Instead, email the project maintainer or open a draft security advisory on GitHub.

We will respond within 48 hours with next steps.

## Scope

This project is open-source and provided as-is. Security issues related to:
- Supabase database access
- Telegram bot token exposure
- XSS or CSRF in the web interface
- Rate limiting bypasses

...are considered in scope.

## Out of Scope

- DDoS attacks
- Social engineering
- Physical attacks
